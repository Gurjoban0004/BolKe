# Punglish evaluation set

Use this as the starting acceptance set. Add only phrases recorded with explicit speaker consent; do not add names, phone numbers, or private messages.

| Dialect/context | Spoken Punjabi (Gurmukhi) | Expected familiar Punglish |
| --- | --- | --- |
| Everyday greeting | ਕੀ ਹਾਲ ਆ, ਤੂੰ ਕਿੱਥੇ ਓ? | ki haal aa, tu kithe o? |
| Family instruction | ਤੂੰ ਮੈਨੂੰ ਲਿਖ ਕੇ ਭੇਜਣਾ | tu mainu likh ke bhejna |
| Majha-style wording | ਜਿਹੜਾ ਮੈਡਮ ਨੂੰ ਭੇਜਣਾ ਜੀ | jehda madam nu bhejna ji |
| Code-switched | ਕੱਲ੍ਹ meeting ਤੋਂ ਬਾਅਦ call ਕਰਾਂਗੇ | kal meeting ton baad call karange |
| Long utterance | ਆਪਾਂ ਬਣਾਇਆ ਆ ਤਾਂ ਜੋ ਦੂਸਰੇ ਦੇ ਫੋਨ ਵਿੱਚ ਚਲਾਣਾ | aapa banaya aa ta jo doosre de phone vich chalana |
| Malwa wording | ਮੈਂ ਹੁਣੇ ਆਉਣੀ ਆਂ, ਰੋਟੀ ਰੱਖ ਲਿਓ | mai hune auni aa, roti rakh lyo |
| Doaba wording | ਤੂੰ ਕਦੋਂ ਘਰ ਆਉਣਾ | tu kadon ghar auna |
| Noisy environment | ਬੱਸ ਦਸ ਮਿੰਟ ਵਿੱਚ ਪਹੁੰਚਦੀ ਆ | bus das mint vich pahunchdi aa |
| Banking language | ਪੈਸੇ ਭੇਜਣ ਤੋਂ ਪਹਿਲਾਂ ਨਾਮ ਚੈੱਕ ਕਰ ਲਓ | paise bhejan ton pehla naam check kar lo |
| Delivery message | ਮੇਰਾ ਪਾਰਸਲ ਕੱਲ੍ਹ ਆਉਣਾ | mera parcel kal auna |

For each release, have at least five native speakers rate every output: **send as-is**, **minor edit**, or **wrong meaning**. Release only when the send-as-is rate is at least 90% and wrong-meaning is below 1% for every represented dialect.

Maintain a separate consented set for natural English-to-Gurmukhi understanding. Cover names, amounts, dates, warnings, links, actions, addresses, delivery updates, banking language, mixed English/Punjabi, and OTP-like text. Rate each result on: **does this explain the message the way a family member would?** Never store real private messages in the corpus.
